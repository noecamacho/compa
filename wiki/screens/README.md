# Screens

There are seven screens; each has acceptance criteria that serve as the QA checklist for its PR (p. 4).

| # | Screen | Route | Page |
| --- | --- | --- | --- |
| 1 | Profile | `/join` | [join](join.md) |
| 2 | Home | `/me` | [me](me.md) |
| 3 | Scan | `/c/[handle]` | [scan](scan.md) |
| 4 | Connection made | `/connection/[id]` | [connection](connection.md) |
| 5 | Summary | `/connection/[id]/summary` | [summary](summary.md) |
| 6 | My connections | `/connections` | [connections](connections.md) |
| 7 | Dashboard | `/live` | [live-dashboard](../live-dashboard.md) (specified in the gamification section, p. 6) |

Global UI rules from the agent contract: mobile first, test at 375 px; `/live` is designed for 1920×1080 (p. 17). The plan's agent contract says the UI is in Spanish (p. 16); see [open-questions](../open-questions.md).
